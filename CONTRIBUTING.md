# Contributing

Thanks for contributing to GamerXD_GZ.

## Before contributing

Please make sure your contribution:

* Does not contain malware or intentionally malicious code.
* Does not include passwords, API keys, tokens, or private keys.
* Does not include copyrighted assets that you do not have permission to distribute.
* Follows the existing project structure.
* Keeps unnecessary dependencies to a minimum.

## Pull Requests

Please explain:

1. What you changed.
2. Why you changed it.
3. How you tested it.

Keep pull requests focused and easy to review.
