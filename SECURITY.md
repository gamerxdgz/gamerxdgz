# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability in this repository, please report it privately rather than publicly posting sensitive details.

Do not include:

* Passwords
* API keys
* Access tokens
* Private keys
* Server credentials
* Other secrets

If GitHub private vulnerability reporting is available for this repository, please use it.

## Security Principles

GamerXD_GZ projects aim to avoid intentionally malicious behavior, hidden tracking, credential collection, and unnecessary data collection.

Third-party dependencies may have their own security policies and should be reviewed separately.
