# Hollow Interval

Original browser horror game by GamerXD_GZ. The complete project is packaged in the companion ZIP delivered with this build.

## Codespaces

```bash
npm install
npm run dev
```

Open forwarded port 5173.

## Controls
WASD move · Mouse look · Shift sprint · Ctrl/C crouch · E interact · F flashlight · Tab inventory · Esc pause.

MIT licensed project code. No game assets are downloaded at runtime.
